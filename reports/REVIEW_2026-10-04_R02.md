## Implementation

Seed and species count are validated as actual TOML integers before RNG
or matrix allocation. Seed must be non-negative; count must be in 1..128.
Unsupported field kernels fail at load time, including inactive tables.
Schema now lists ring only. No new config field, numerical kernel, seed
offset, optional backend dependency or tolerance was changed.

The schema guard compares every top-level/table key set, unknown-key
policy, rules enum, field-kernel enum and seed/count type/bounds using the
standard library. It is not a general JSON Schema validator.
